# CNC AI Android MVP 0.2.0

Первая исходная версия Android-приложения CNC AI.

## Что уже реализовано
- Нативный Android-интерфейс на Java без сторонних библиотек.
- Предварительный эвристический анализ фрагментов G-кода.
- Калькулятор оборотов по Vc и D.
- Калькулятор минутной подачи по подаче на оборот и оборотам.
- Локальные заметки через SharedPreferences.
- Импорт текстовых NC/TXT/ISO файлов через системный выбор файла.
- Расширенный предварительный разбор встречающихся групп G/M-команд и предупреждений.
- Экспорт отчёта через системное меню «Поделиться».
- Локальная карточка станка: модель, стойка, оси/кинематика и примечания.
- Навигация между разделами.

## Сборка APK
1. Установить Android Studio (актуальная версия) и Android SDK Platform 35.
2. Открыть папку проекта `CNC_AI_Android_MVP`.
3. Дождаться синхронизации Gradle.
4. Выбрать Build -> Build Bundle(s) / APK(s) -> Build APK(s).
5. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

Требуется JDK 17 и Android Gradle Plugin 8.7.3. При первом открытии Gradle может скачать зависимости, поэтому интернет нужен для первоначальной сборки.

## Важные ограничения
Это MVP для проверки интерфейса и базовых функций. Анализатор не является постпроцессором, симулятором или верификатором УП. Он не учитывает конкретную модель станка, параметры Fanuc, кинематику, смещения, макросы, циклы OEM и столкновения. Не загружайте программу в станок только на основании результата приложения.

## Самый простой способ получить APK без Android Studio

В проект добавлена автоматическая сборка GitHub Actions (`.github/workflows/build-apk.yml`).

1. Создай бесплатный репозиторий на GitHub.
2. Загрузи туда всё содержимое этой папки, включая скрытую папку `.github`.
3. Открой вкладку **Actions** репозитория.
4. Выбери **Build CNC AI APK** и нажми **Run workflow** (если сборка не стартовала автоматически после загрузки).
5. После завершения открой запуск workflow, найди **Artifacts** и скачай `CNC-AI-debug-APK`.
6. Распакуй архив и установи `app-debug.apk` на Android. При необходимости Android попросит разрешить установку приложений из этого источника.

Это debug APK для тестирования. Он не подписан отдельным релизным ключом и пока не предназначен для публикации в Google Play.
